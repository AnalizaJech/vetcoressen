VOUCHER: POR QUE NO IMPRIME EN A4 (encontrado)

voucher.blade.php usa el layout guest.blade.php, cuyo <body> tiene
class="h-screen overflow-hidden ... flex items-center justify-center" y
adentro un <main class="relative ... h-full overflow-y-auto">. El CSS de
impresion del voucher solo resetea el body (height:auto,
overflow:visible), pero NO resetea el <main>: como main sigue con
position relative + altura fija + overflow controlado, el
#voucher-imprimible (que es position:absolute) queda atrapado dentro del
main en vez de ocupar la hoja completa, por eso no aparece el comprobante
al imprimir. Fix, agregar "main" al reset dentro del @media print del
voucher:

body, main {
    background: white !important;
    height: auto !important;
    overflow: visible !important;
    position: static !important;
}

(agregar esa regla junto a la que ya existe para "body" en el
@media print de voucher.blade.php, dejando el resto igual).

BOTON DE IMPRIMIR: POR QUE NO SE VE

El boton "Imprimir Comprobante" esta arriba de todo el contenido del
voucher, y como el layout centra todo verticalmente en una pantalla fija
(h-screen, overflow-hidden en el body), si el comprobante es mas alto que
la pantalla el boton puede quedar fuera de la vista inicial. Cambiar su
posicion a fija/flotante para que siempre se vea sin importar el scroll:

.print-btn-container {
    position: sticky;
    top: 1rem;
    z-index: 20;
}

PATRON PARA CUALQUIER OTRA VISTA DE IMPRESION (historia clinica, etc)

Cuando se construya la vista de imprimir historia clinica u otro
documento, usar el mismo patron ya corregido arriba (reset de body Y main,
contenido con fondo blanco y texto negro fijo, no depender de las
variables del tema oscuro), para no repetir este mismo bug en cada vista
nueva que se imprima.

CORREO (RESEND): RECORDATORIO

El codigo ya esta conectado (sendCitaNotification, sendPagoNotification).

colas corriendo escuchando la cola 'emails'

sin importar que tan bien este configurada la API key.

Ya hay rastros de la conexion (referencias a la cita en
HistoriaClinicaForm.php y en cita-index.blade.php). Antes de seguir

ya existe una) cual de los 5 pasos falta o quedo a medias, en vez de
rehacerlo de cero.
